# 用語 SSoT

yatima プロジェクトで使う用語の Single Source of Truth。
全 epic.md / spec.md は **この辞書に従う**。別名・略称・表記揺れは禁止。

---

## ドメイン用語

| 用語 | 定義 | 別名禁止リスト | 関連 |
|------|------|---------------|------|
| フィード | 購読対象の RSS / Atom 配信元（1 つの URL に対応） | feed / 購読元 / チャンネル → 全て「フィード」 | [記事] |
| 記事 | フィードから取得した個々のエントリ | entry / item / エントリ / ポスト → 「記事」 | [フィード] |
| 収集 | フィードを取得・パースして新着記事を保存する一連の処理 | fetch / クロール / 巡回 / ポーリング → 「収集」 | [フィード, 記事] |
| 既読 | 利用者が一度開いた（読んだ）記事の状態 | read / 閲覧済み → 「既読」 | [記事] |
| 未読 | まだ開いていない記事の状態 | unread / 新着 → 「未読」 | [記事] |
| フィード登録 | 新しいフィード URL を購読対象に追加する操作 | subscribe / 購読追加 → 「フィード登録」 | [フィード] |
| guid | 記事の一意識別子（RSS の guid / Atom の id）。無い場合は記事 URL で代替 | id / 識別子 → 文脈上「guid」 | [記事] |

## ステータス語彙

| 対象 | フラグ | 意味 | 値 |
|------|--------|------|-----|
| 記事 | is_read | 閲覧状態 | false（未読・初期値）/ true（既読） |
| フィード | active | 収集対象か | true（収集する・初期値）/ false（停止中） |

## 数量・閾値

| 名前 | 値 | 根拠 |
|------|-----|------|
| 収集間隔（cron） | 1 時間ごと | 個人利用で十分な鮮度。GitHub Actions の無料枠を圧迫しない |
| 一覧 1 ページあたり | 50 件 | UI 表示パフォーマンス |
| フィード URL 最大長 | 2048 文字 | 一般的な URL 長上限 |
| 1 収集あたりのフィード取得タイムアウト | 10 秒 | 遅いフィードで収集ジョブ全体が詰まるのを防ぐ |

---

## 別名禁止メタルール

1. 同義語を見つけたら左カラムに正規形を残し、右カラムに別名を列挙する
2. epic.md / spec.md 執筆時、別名を使った時点で `bdd-spec-evaluate`（Phase 2）が warning を出す
3. 新規用語は spec.md / epic.md の「用語」セクションで導入 → 確定後に all_spec.md へ昇格
